# Introducción a la fotosíntesis

La fotosíntesis es el proceso mediante el cual las plantas convierten
la energía luminosa en energía química.

<!-- section:end id="01JCK8M2QX4F7K9W3B6H5T1R8A" -->

<!-- section:start id="01JCK8N5A2C6D9E4F7G1H3J8K0" -->
## Fase luminosa

Esta fase ocurre en las membranas de los tilacoides.

- La clorofila absorbe la luz.
- Se produce ATP.
- Se libera oxígeno.

<!-- section:end id="01JCK8N5A2C6D9E4F7G1H3J8K0" -->

<!-- section:start id="01JCK8P7B3D5F9H2K6M4N1Q8R0" -->
## Ciclo de Calvin

El ciclo de Calvin utiliza ATP para fijar dióxido de carbono.
